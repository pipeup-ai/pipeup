Add Pipeup to a page

One script tag, pinned to a version, and a document key that stays the same once people have commented.

The html tag
<html data-pipeup-doc="MQQLnEw1V1KQtXotdXeyksEYEB60YVpvSh65pKhcG38">
Just before the end of body
<script
  src="https://cdn.jsdelivr.net/npm/pipeup@0.8.2/dist/pipeup.min.js"
  integrity="sha384-…"
  crossorigin="anonymous"
></script>

Make a key in any browser console on a page with Pipeup loaded: await Pipeup.newDocumentAttribute()

One file, no dependencies: put pipeup.min.js next to the page and it works from disk.
