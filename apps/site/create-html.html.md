# Adding Pipeup is now on the home page

Making a page to share? Adding Pipeup is now the home page's four steps: copy the prompt, paste it into your AI with your HTML file and save the new file it gives back, send that file with the note your AI writes, and paste the comments you get back into your AI.

The home page's Markdown copy has them in full: [index.html.md](https://pipeup-ai.github.io/pipeup/index.html.md).
