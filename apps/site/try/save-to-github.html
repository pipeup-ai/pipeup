Example: not from Pipeup

Try Save to GitHub

  1. Press Shift+Option+C (Shift+Alt+C on Windows), select some words and write a comment.
  2. Open the comment control's menu and choose Save to GitHub. Name a repository you can write to, and it shows the address it would open and the file it would fill in.
  3. Press Open GitHub to see GitHub's own "new file" page with the review filled in. You commit it yourself; nothing is sent from here.

What it is An add-on a company writes for itself. It needs no server and no token: GitHub's own page and your own sign-in do the saving.

Use it for real Copy the prompt and give it to your AI agent: it adds the add-on to your page. It only needs the repository's name. For long reviews or a team, see Send to Git or the guide.
