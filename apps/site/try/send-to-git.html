Example: not from Pipeup

Try Send to Git

  1. Press Shift+Option+C (Shift+Alt+C on Windows), select some words and write a comment.
  2. Open the comment control's menu and choose Send to Git. It tells you what it would send, and asks first.
  3. Press Send. Here you see exactly what would be sent. Nothing leaves your browser.

What it is An add-on a company writes for itself. It sends the review, as the Markdown that Copy as Markdown makes, to a service the company runs, which files it in Git. It never holds a Git token.

Make it real Run it on your computer with a service that really commits the file, or read the guide.
