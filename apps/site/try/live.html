Try Live

  1. Open this same page in a second browser, a private window or another device (a second tab in the same browser counts as the same person). Copy the address below if it helps.
  2. In each, press Shift+Option+C, open the menu and choose Go live. Each window asks first.
  3. Move your pointer, select words and comment: the other window shows your named cursor and the people present.

Sends Presence and comments, browser to browser. Public relays only introduce the windows to each other; they can't read anything.

Needs Two windows that are separate people (not two tabs of one browser), and a browser with WebRTC.
