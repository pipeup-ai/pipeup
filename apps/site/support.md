# Support

Help with Pipeup for browsers, the extension that lets you comment on any web page.

## Getting started

- **Install** Pipeup from your browser's store: Chrome Web Store, Microsoft Edge Add-ons, Firefox Add-ons, or the Mac App Store for Safari.
- **Pin it** to the toolbar from the browser's extensions menu (the puzzle piece). In Safari, open Safari Settings, then Extensions, and turn Pipeup on.
- **Comment on a page:** open any web page, press Pipeup in the toolbar (or Shift+Alt+P) and choose **Comment on this page**. Click what you want to comment on, type, and press Enter.
- **Read the comments:** press Pipeup again and choose **Comments**.
- **Get them out:** **Copy comments** puts them on your clipboard as Markdown or text, ready to paste into a message or an AI chat. **Save comments** saves them as a file.

## Common questions

- **Pipeup says it can't run on this page.** Browsers keep some pages closed to every extension: their own settings and new-tab pages, store pages, and files they draw themselves such as PDFs.
- **Pipeup says the page has its own Pipeup.** The page's author added Pipeup to it. The extension steps aside so there is only one; comment with the page's own.
- **My comments are gone.** Comments are kept in the browser where you wrote them, by page address. They aren't in another browser or on another computer, and clearing the browser's data for extensions removes them. Comments on a page whose address changed are under **Comments you've made** in Pipeup's settings.
- **Send to my agent says to run a command.** It sends comments to AI agents on your computer through a small helper. Run the command it shows once in a terminal (Node.js is needed). It works on macOS and Linux, in Chrome, Edge and Firefox.
- **Firefox asks before sending.** Firefox asks you to agree before Share, Live or Save to GitHub is turned on, or before Send to my agent first sends. Decline, and that feature stays off.

## Your privacy

Pipeup has no account and no server of its own, and collects nothing. What it keeps stays in your browser; what leaves it, and when, is in the [privacy policy](privacy.html).

## Report a problem or ask a question

Open an issue on [GitHub](https://github.com/pipeup-ai/pipeup/issues). Say which browser and version you use, the page's address if you can share it, and what you did and saw. A problem with privacy or security can be reported privately through [GitHub's security advisories](https://github.com/pipeup-ai/pipeup/security/advisories/new).
