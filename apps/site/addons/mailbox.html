Your own mailbox

A small server you run for Share, so even sealed comments stay inside your organisation.

Sends Sealed comments, to a server you run. It holds ciphertext and never sees the key.

Asks first Nothing changes for reviewers: Share still asks before anything is sent.

Needs Node 22 or newer, and an HTTPS proxy in front of it. Pipeup doesn't run a mailbox for anyone, so there is no online try: it needs a server of your own.
