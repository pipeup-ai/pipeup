Quick start on the home page

A visitor copies one prompt, pastes it into their AI agent with their HTML file, and the agent adds Pipeup. The prompt is the one the "Create comment-enabled HTML" page already copies, so the site still has one prompt for putting Pipeup in a page.

What changes

  • The home page gets a Quick start section under the first screen, above the footer: a heading, one sentence, three short steps and the prompt's words with a Copy prompt button.
  • The first screen doesn't change: the headline, the two buttons, the shortcut and the showcase stay as they are. On a laptop the Quick start's heading peeks in at the bottom of the window, so people see there is more.
  • The prompt is shown, not hidden behind the button, so people can read what they are about to give their agent. It is the same text the button copies, including a fresh document key made in their browser.
  • After a copy the button reads Copied with a check, then eases back to Copy prompt. Nothing snaps: the label and icon cross-fade both ways. The walkthrough pages' Copy prompt buttons ease back the same way.
  • The page's Markdown copy and llms.txt get the same Quick start, in words.

Where it sits

Under the hero and above the footer, on the same two columns as the hero, so its left edge lines up with the headline and the prompt lines up with the showcase. A hairline above it separates it from the first screen.

Add Pipeup to this HTML page (or the one you are making) so the people I share it with can comment on it right on the page.

1. Add <script src="https://cdn.jsdelivr.net/npm/pipeup@0.8.2/dist/pipeup.min.js"></script> just before </body>. Edit only the HTML file: there is nothing to download or run.

The button's states

One button, three moments. The label and the icon cross-fade; the button keeps its width, so nothing beside it moves.

1 · Ready Copy prompt

Hover darkens it a little; keyboard focus shows the violet ring. Press shrinks it slightly (0.98).

2 · Copied (0 to 2 seconds) Copiedprompt

The check eases in from a little smaller; "Copied" fades in as "Copy prompt" fades out. Screen readers hear "Prompt copied".

3 · Easing back (after 2 seconds) Copy prompt

Copy prompt and its icon fade back in over about a third of a second. Clicking again copies again and restarts the two seconds.

If copying fails Copy prompt

The prompt's text is selected in its box, so the visitor can copy it themselves; the button doesn't claim "Copied".

At phone width

The two columns stack: heading, sentence and steps first, then the prompt box, a little shorter. The button keeps its size and stays in step 1, within thumb reach. The text wraps; nothing scrolls sideways. On a touch screen without a keyboard step 3 reads "Open the page and tap the comment button" instead of showing keys.
