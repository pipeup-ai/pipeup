Pipeup for your browser, offered once

A page with Pipeup built in tells a reviewer, in its own menu, that Pipeup exists for their browser too: one quiet row, only where the extension is public, gone for good when they say so.

Visual spec · core library (not the extension) · 27 November 2026 · for the functional spec §7 (the menu) and §16 (distribution)

The shape. One row at the top of Pipeup's ⋯ menu, Pipeup for Chrome (the browser's name changes), with a browser glyph. Pressing it opens two choices beneath, the way Copy comments does: Get it from the Chrome Web Store and Don't tell me again. Either choice ends the offer on this site.

Shown only when the reviewer's browser has a public listing, the page draws Pipeup's own menu, the screen has a pointer or keyboard, and nobody has ended the offer here.

Costs nothing on the network (the list of browsers ships inside Pipeup) and about 0.4 KB of the 53 KB budget.

When the row shows

Each question is asked in order when the menu opens. The first "no" means no row, and nothing else changes.

1
Is this a browser Pipeup has a public extension for?
Known from the browser's own name (Chrome and the browsers built on it, Safari, Edge, Firefox), against the list shipped in this build. Phones and tablets: no row, there is no extension for them yet.
2
Is this Pipeup's own menu on the page?
A host that draws the menu itself (the extension's toolbar menu, a page with its own) shows no row: either the extension is already here, or the page chose its own words.
3
Has the page's author left the offer on?
An author who would rather their page said nothing about extensions turns it off with one attribute, data-pipeup-extension="off": no row, ever, on that page.
4
Has this reviewer ended the offer on this site?
Choosing the store, or Don't tell me again, is remembered where Pipeup keeps the reviewer's other choices (Theme, Hide comments). No row after that, on any of this site's pages, in this browser.
✓
The row shows, at the top of the menu.
Farthest from the hand (the menu rises from the control; Start commenting stays nearest it), first to read, easy to pass over. The arrow keys reach it like any row.

Pipeup can't tell whether the extension is already installed: an extension that is off for this page is invisible to it, and it makes no network request to ask. So the offer leans on being quiet and on going away for good. It is never a toast, a bubble or a badge; it never opens on its own; it is in the menu or nowhere.

Which browsers, which stores

The list ships in the build and changes only with a release. A browser is on it once its listing is public; until then its reviewers see nothing, which is also what every browser not on the list sees (Brave, Arc and the rest install from the Chrome Web Store, so they count as Chrome).

Edge reports itself as Chrome as well as Edge, and Safari's name appears in Chrome's; the check reads the most specific name first, as Pipeup's extension already does when it decides which rows to offer. A wrong guess only sends someone to a store that says "not for this browser", which is why the first choice names the store.

How it behaves, in full

  • Where it is. First in the ⋯ menu, above the name row, with a separator under it. Nowhere else: not in All comments, not by the control, not in a comment box, never a toast.
  • What it looks like. An ordinary row: the browser glyph, one line of words, › at the end. It is not coloured, bold, badged or marked new. In the dark look it is drawn as every other row is.
  • Pressing it opens the two choices beneath with the same easing as Copy comments; a second press, ←, or Esc folds them. The choices are folded each time the menu opens.
  • Get it from the store opens the store's listing in a new tab and closes the menu. It also ends the offer on this site: the reviewer has been shown the way, and the store is where it continues.
  • Don't tell me again ends the offer on this site at once. The row and its choices ease out (height and opacity, over Pipeup's usual quick motion); the menu stays open, so the reviewer sees it go; focus moves to the name row.
  • Remembered where Theme and Hide comments are: in this browser, for this site. Pipeup keeps nothing across sites and asks no server, so a reviewer who said no here may see the row again on another author's page. Said plainly in the tooltip.
  • Keyboard. ↑ ↓ Home End reach the row; Enter or → opens the choices; Enter chooses one; ← or Esc folds them; Esc again closes the menu. Nothing about the menu's existing keys changes.
  • Touch. No row on a screen with only touch: there is no extension to install there.
  • Authors. data-pipeup-extension="off" keeps the row off a page; pipeup init doesn't set it. Nothing else is configurable: no custom words, no custom link.
  • Network and privacy. None, until the reviewer presses the store choice, and then it is the browser opening a page, not Pipeup. The row's presence tells no one anything.
  • Size. About 0.4 KB gzipped: the browser check, the row, two choices, one preference. Within the 53 KB budget; counted in `scripts/size.mjs` when built.

Not in this design

  • Knowing whether the extension is already installed (it would need the extension to announce itself on every page, which it doesn't do, and shouldn't).
  • A "remind me later" or any return of the row after it has been ended.
  • A row in the extension's own menu pointing the other way (to adding Pipeup to a page): that is the author's story, told on the website.
  • Telling anyone the row was shown, pressed or ended.
