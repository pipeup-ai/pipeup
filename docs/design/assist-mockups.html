Assist: short replies from a model on your device

Once turned on, a small AI model that runs on the reviewer's own machine looks at each comment in the background and decides whether a reply would help. If it would, it adds a short reply, written like a person would write it, streaming in as it is made. If there is more to say, the reply links to it. Nothing leaves the device. Working name: Assist.

1. The first time: asked first, in plain words

Nothing runs until the reviewer says yes. The panel says where the model is, what it costs the machine, and that nothing leaves it. Two cases: the browser already has a model, or one has to be downloaded.

5. When it can't, it says why

AIAssistant replies are off on this device
This device doesn't have the memory the model needs. Comments and replies work as usual.
Too little memory (or no graphics support, or a metered connection for the download). One plain sentence; nothing else changes.
AIThat didn't work
The model stopped before it finished, so nothing was added. It will try again with the next comment.
A failure. Nothing half-finished is ever left in a thread. No codes or stack traces.

What changes for people who don't use it: nothing. The add-on is a separate script. A page without it, or a reviewer who never turns it on, sees no new row, loads no model and uses no extra memory.
